# Sarah Almanjahi Portfolio

This project is a personal portfolio website created for SWE 363 Assignment 1.

## Project Description

The portfolio introduces me as a Software Engineering student and presents some of my academic projects. It also includes a contact form and a simple JavaScript greeting feature.

## Features

- About Me section
- Projects section
- Contact form
- Responsive design for different screen sizes
- Time-based greeting using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Project

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation is required.
